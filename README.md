🌱 스마트화분 프로젝트 (Smart Plant Pot)
카카오톡 챗봇을 통해 원격으로 제어할 수 있는 라즈베리파이 기반 스마트화분 시스템

📋 프로젝트 개요
이 프로젝트는 라즈베리파이와 각종 센서를 활용하여 식물의 상태를 모니터링하고, 카카오톡 챗봇을 통해 원격으로 제어할 수 있는 스마트화분 시스템입니다. 사용자는 카카오톡을 통해 식물의 상태를 확인하고, 물주기, 조명 제어 등의 기능을 원격으로 수행할 수 있습니다.

🏗️ 시스템 아키텍처
[카카오톡 챗봇] ←→ [Django 스킬 서버] ←→ [Flask 라즈베리파이 서버] ←→ [하드웨어 센서/액추에이터]
구성 요소
카카오톡 챗봇: 사용자 인터페이스 역할
Django 스킬 서버: 카카오톡 API 처리 및 비즈니스 로직
Flask 라즈베리파이 서버: 하드웨어 제어 및 센서 데이터 수집

🛠️ 기술 스택
Backend
Django: 카카오톡 스킬 서버
Flask: 라즈베리파이 제어 서버
Requests: HTTP 통신
Hardware
Raspberry Pi 4: 메인 제어 보드
센서 모듈들:
토양 습도 센서
온습도 센서 (DHT22)
워터펌프
LED 조명
릴레이 모듈
API & Integration
카카오톡 오픈빌더: 챗봇 플랫폼
Kakao i Open Builder Skill: 스킬 서버 연동


⚙️ 주요 기능
1. 모니터링 기능
실시간 토양 습도 측정
데이터 로깅 및 히스토리 관리
2. 제어 기능
자동/수동 물주기 시스템
LED 조명 제어 (밝기, 시간 설정)
알림 및 경고 시스템
3. 챗봇 인터페이스
현재 상태 조회
원격 제어 명령
🔄 시스템 플로우
1. 상태 조회 플로우
사용자 → 카카오톡 챗봇 → Django 서버 → Flask 서버 → 센서 데이터 수집 → 응답 반환
2. 제어 명령 플로우
사용자 → 카카오톡 챗봇 → Django 서버 → Flask 서버 → 하드웨어 제어 → 결과 확인 → 응답 반환



🔔 알림 및 경고 시스템
토양 습도 부족 시 자동 가습기작동
온도 이상 시 경고
정기적인 상태 리포트
"상태 확인": 현재 식물 상태 조회
"물주기": 수동 물주기 실행
"조명 켜기/끄기": LED 조명 제어
"설정": 알림 및 자동화 설정
